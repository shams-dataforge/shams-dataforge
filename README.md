### 🔬 Featured Research Software

**[Sequence Function Predictor](https://github.com/shams-dataforge/sequence-function-predictor)**

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24059064.svg)](https://doi.org/10.5281/zenodo.24059064)

A Streamlit-based application for evidence-based, ortholog-based functional annotation of biological sequences.

- Supports protein FASTA, DNA transcripts/CDS, and prokaryotic genome sequences.
- Integrates eggNOG-mapper for functional annotation.
- Reports per-protein annotation evidence and confidence categories.
- Provides GO and KEGG annotations and enrichment analysis.
- Supports CSV and Excel exports.
